# planta-vida
Um diário digital de cuidado e crescimento de plantas.

Me chamo Luís, estudante de Sistemas de Informação, na Universidade Federal de Viçosa - 
Campus Rio Paranaíba.

Este também é um projeto, com finalidade de criar um site básico, onde o usuário registra seus cuidados com sua platinha, em que reforço meus conhecimentos em HTML e CSS.

O **Plantar é Vida** é um projeto web desenvolvido com o objetivo de praticar e consolidar conhecimentos fundamentais em HTML e CSS, criando uma interface simples para registrar e acompanhar plantas e seus cuidados. Tive essa ideia, e por mais que fosse difícil estruturar, me dediquei para que fosse algo real e palpável.

Este projeto representa um passo importante na minha jornada de aprendizado em desenvolvimento web, consolidando conceitos do nível básico ao intermediário em HTML e CSS, como:

Estrutura semântica de páginas
Organização de layouts com Flexbox
Estilização e identidade visual básica
Interatividade com um hover e transições
Estruturação de seções e componentes
Introdução à responsividade

---

## 🧩 Funcionalidades atuais

- Apresentação da proposta do projeto
- Registro de uma planta no "jardim"
